# Tracks this server rotates through.
#
# One category/track per line; blank lines and # comments are ignored. Delete
# the file to race every track the server has installed.
#
# Three things narrow the list, and all three matter:
#
# 1. The players have to have the track. A dedicated server has every track the
#    game ships, a headset has the one bundled in its build plus whatever has
#    been downloaded since - and racing a track a player does not have leaves
#    them unable to load it.
#
# 2. The track has to ship shadow2.png, the map of vertical shadows cast onto
#    cars. Without it nothing modulates the car materials and every car renders
#    noticeably brighter and flatter. The log says so when it happens:
#      "shadow2.png/rgb not found ; no shadow mapping on cars for this track"
#
# 3. The gt2-* circuits are prototypes. They ship without a 3D model and only
#    get one when the track generator is run over them during a build, so a
#    server built from source has them and a headset does not.
#
# What is left is the standard circuits. jarama is in as well, by choice: it is
# the one track bundled in the headset build, so it is the only one a fresh
# install can race without downloading anything first. It has no shadow2.png,
# so the cars do look brighter there than on the rest.
